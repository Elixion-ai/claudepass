# Issue tracker

Issues for this repo live in **Elixion**, project key **CLA** (ClaudePass), accessed through the `plugin:elixion:elixion` MCP tools.

- Work items: `TASK` issues filed under an `EPIC` via `epic_id`.
- Dependencies: `BLOCKED_BY` links via `manage_issue_link`.
- PRD, glossary, and ADRs: Elixion documents (also mirrored in `docs/` in this repo; the repo copy is canonical for the domain glossary and ADRs, Elixion is canonical for issue state).
- Transitions: `transition_issue_status` (BACKLOG → TODO → IN_PROGRESS → IN_REVIEW → TESTING → DONE).
- Evidence and work logs: `add_issue_evidence`, `add_work_log`, `add_issue_comment`.

PRs as a request surface: off.
