# The brand colour is arcade amber, chosen despite the Anthropic-proximity caveat

The retro arcade landing shipped with a phosphor-green palette, and the Brand & UI epic recorded a rule to avoid orange because the name already borrows "Claude" and an orange identity on top of it reads as an Anthropic sub-brand. On 2026-09-10 the owner chose orange anyway, asking for "Claude Code orange". We implemented it as arcade amber (#ff8a1f primary, #b85a10 dim, warm-tinted neutrals) rather than Anthropic's terracotta (#D97757 / #C15F3C): the hue sits in the amber-phosphor family of 1980s monitors, which keeps the retro concept honest and gives a defensible distance from Anthropic's swatches. The non-affiliation disclaimer stays on every page. Consequence: the brand book (CLA-27) must tokenise this amber, and any future palette work must keep the distance from terracotta rather than drift toward it.
